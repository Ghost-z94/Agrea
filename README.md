# AGREAS

**AGREAS** es un videojuego de **Survival Horror cooperativo en línea** con estética *Low Poly*, ambientado en unas alcantarillas hostiles en el año **2010**.

Enfrentaos a la oscuridad y la presión constante mientras cooperáis para reunir **objetos rituales** —en una cantidad equivalente al **número de jugadores más dos adicionales**—, reconstruir el altar y sellar al demonio **Agreas**.

---

## Características principales

* **Cooperación bajo presión:** Trabajad en equipo en un entorno subterráneo opresivo para completar el ritual antes de que la amenaza os supere.
* **Roles o habilidades aleatorias:** Cada partida asigna al azar uno de cuatro roles o habilidades únicas: **Vida**, **Distracción**, **Exploración** y **Energía**.
* **Terror psicológico y escasez:** Una interfaz minimalista y recursos limitados —como la batería de las linternas— buscan acentuar la vulnerabilidad y la carga mental.
* **Estilo *Low Poly* de 2010:** Dirección visual nostálgica y depurada pensada para acompañar la atmósfera claustrofóbica de las alcantarillas.

---

## Controles principales (PC)

| Tecla / Acción | Función |
| :--- | :--- |
| **WASD** | Moverse por el escenario |
| **F** | Encender o apagar la linterna |
| **Mouse** | Interactuar con objetos y el entorno |
| **P** | Abrir el menú |

## Requisitos y ejecución

* **Plataforma:** PC (requiere conexión a Internet para jugar en modalidad *online*).
* **Rendimiento:** Diseñado como un título de **bajo peso** y **requisitos de hardware de gama media/baja**.
